# TIYA 文档

TIYA（Then I Ask You）是一个以 QQ 群聊和私聊为交互环境的个人 AGI 工程 Demo。它的重点不是提供一个开箱即用的聊天机器人产品，而是验证一组可以组合工作的工程能力：Agent 主控、异步任务机、上下文压缩、长期记忆、Persona，以及按需加载的 SKILL。

本项目当前对接 NapCat / OneBot 消息环境，使用兼容 OpenAI Chat Completions 接口的模型作为主要推理后端。

## 项目看点

- **Agent 与发言模型分离**：主控负责理解、规划、调用工具和维护任务，Speaker 负责把决策转换为符合角色设定的最终发言。
- **任务执行脱离单次 LLM 请求**：工具调用可以进入带优先级、依赖、重试、超时和回调策略的异步任务机。
- **可恢复的上下文管理**：当前窗口、历史窗口、事件历史、任务状态和检查点分别保存，长对话可以压缩后继续工作。
- **分层长期记忆**：记忆不是简单追加到一个文本文件，而是经过分桶、递归查询、重排、压缩、拆分和版本管理。
- **渐进式 SKILL**：Agent 先看到能力摘要，再按标题树读取所需说明，必要时加载附属 Python 工具，避免一次性占满上下文。
- **群聊关系建模**：相关性模块从消息连续性、话题和成员兴趣等信号计算发言倾向，作为群聊决策的补充。

## 文档范围

文档主要说明当前代码中已经存在的设计和实现，不把 TIYA 描述成通用 Agent 框架，也不承诺生产级可用性。Pixiv、OCR、图片搜索和自动收藏等模块用于展示工具扩展能力，只在架构图和配置说明中简要出现。

代码仍处于个人项目演进阶段，部分模块的命名和接口会继续调整；架构文档关注稳定的职责边界和数据流，而不是逐个函数罗列 API。

在运行带有外部工具或自定义 SKILL 的 Agent 前，请先阅读[已知限制](limitations.md)。当前版本没有完整的 Agent 权限系统，也没有真正的代码运行沙箱。
